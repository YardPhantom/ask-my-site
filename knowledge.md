# Sample Knowledge Base

## What is Ask My Site?
Ask My Site is a tiny self-hosted FAQ chatbot. It answers questions from a single Markdown file using keyword matching, so no API key is needed.

## How do I edit the answers?
Edit knowledge.md. Each "## Heading" is a question or topic and the paragraph under it is the answer. Restart the server to reload.

## Who built this?
Ask My Site was built by Trevor Heshka. See https://trevorheshka.com for more projects.

## Does it need an API key?
No. Matching uses TF-IDF scoring over the knowledge file. You can optionally plug in an LLM later.
